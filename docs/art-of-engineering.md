## Creative direction and milestones

1. **Identity / ink:** a full-name title in Manrope, Instrument Serif as a contrasting voice, one original satin-metal band and a reversible passage through its negative space. No orbiting cubes, particle field, ground grid or loading gate.
2. **Person / paper:** readable editorial copy with generous asymmetry. Education, the full skill taxonomy, experience and credentials follow before the work.
3. **Work / ink:** large real captures on restrained individual surfaces, an eight-project staggered index, explicit scope labels and intentional hover previews. The image frame expands into the native case view without stretching screenshot pixels. Closing returns to the source when it is visible.
4. **Experiment / sage paper:** a professional tool surface with Learn, Inspect and Challenge around one persistent prediction field. Real model behavior is retained.
5. **Conversation / paper:** a large typographic invitation, direct email and professional links. No decorative 3D footer.

Palette: ink, warm paper, muted sage and copper. The UV mark is retained. The sculpture is procedural geometry; screenshots and records come from the existing projects. No reference assets or AI-generated imagery are used.

## Motion and rendering

Native scroll supplies one reversible progress parameter to the opening; one renderer owns its camera. The geometry opens into a planar aperture as the camera moves forward. Pointer motion is bounded and settles; there is no constant object rotation. The title and lower copy leave together. At the end the surface resolves into the personal chapter.

Other chapters are native HTML. A small set of masked title entrances, short section cuts, category changes, link arrows and shared-image expansion provides a common language. Long navigation skips intervening chapters rather than initializing every experiment in a fast scroll. The section-cut and project-close paths guard interruption and stale completion.

Only the hero can load Three.js, and only when its section is visible without an open dialog. Save-data and explicit no-graphics paths keep the inline vector form. A display visibility observer controls the one demo engine. Model training uses the existing worker and visibility messages. Context loss keeps the fallback; page teardown disposes graphics and stops loops. Pixel ratio is capped, with no bloom or postprocessing pipeline.

The source index and studio are not replaced with a new framework. Static GitHub Pages deployment is unchanged.
